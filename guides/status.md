# 能力范围

项目定位：本地单用户 Web UI 评测 Harness。

| 状态                            | 能力                                                                                                                         |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 已实现，有工程测试              | 固定 Chromium 截图、sharp/pixelmatch/SSIM、标注区域几何与文字、交互检查、SQLite 队列、证据文件、工作区 manifest 复核、报告页 |
| 已实现，需真实任务验证          | 简化 MCP、基础响应式越界检查、Controller 命令适配与修复策略                                                                  |
| 初步便利层                      | 依赖/入口识别；根目录 HTML 正则区域建议                                                                                      |
| 首版已实现，待真实Agent效果验收 | 自动差异区域定位、成对裁剪图、运行时DOM关联、前后轮变化；见 [视觉反馈设计](visual-feedback-design.md)                        |
| 未实现                          | OCR 识别、视觉模型解释、完整区域确认界面、操作系统安全沙箱、CSS Modules 自动检测                                             |
| 未完成验收                      | 正式90分校准、真实模型多轮收敛、跨系统渲染一致性                                                                             |

MCP 默认五个工具，owner 十个工具；workspace 是唯一源码执行模式；详见 [接口文档](mcp.md)。修复策略目前只注入 Controller，MCP 使用方依据报告自行决策。

默认权重为 0.35/0.20/0.30/0.15，可由 owner 配置。它们是权重而非客观还原百分比。当前 provisional 配置即使100分也不会 pass。

Figma 输入暂不在范围内。多用户服务、远程平台、云端队列、企业权限和分布式存储不是当前设计目标。安全隔离属于未来本地执行能力，目前务必阅读 [安全边界](../SECURITY.md)。

近期优先级：真实项目接入与反馈质量、可确认的区域建议、独立校准数据、受验证的编码工具适配。未列发布日期承诺。
