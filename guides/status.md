# 能力范围

项目定位：本地单用户 Web UI 评测 Harness，输入参考图和已运行的目标 URL。

| 状态                          | 能力                                                                                                              |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 已实现，有工程测试            | 外部 URL Chromium 截图、sharp/pixelmatch/SSIM、标注几何/文字、交互检查、响应式探针、SQLite 队列、证据存储、报告页 |
| 已实现，有真实 stdio MCP 测试 | 五工具与 CLI 共享合同，创建 → 提交 → 状态 → 修复重评 → finalize / cancel                                          |
| 已实现，待真实 Agent 验收     | 差异区域、局部对照图、DOM 关联、轮次变化、Skill 和 Codex Stop hook                                                |
| 未实现                        | OCR 服务、Harness 内置视觉模型解释、完整区域确认界面、App 采集适配器、网络沙箱                                    |
| 未完成验收                    | 正式90分校准、真实 Codex 对话多轮收敛、跨系统渲染一致性                                                           |

不提供目标项目构建/启动/停止、源码扫描或代码修改。目标 URL 必须由 Codex 或开发者保持可访问。

无标注时默认使用 pixel_diagnostic 权重 0.65/0.35；新建标注导入任务同样使用图像主分权重 0.65/0.35，标注分单列诊断。这些是指标权重，不是客观还原百分比。默认 provisional 配置可按阈值验收，校准状态仅作说明。测试使用的 validated fixture 仅验证状态机，不代表产品校准。

finalize 仅确认指定采集证据通过，不验证源码/构建来源，不保证 URL 之后的内容仍相同。Figma、App、多用户远程服务尚未接入。

已实现 Codex 标注工作流指引、参考/DOM 映射合同、Pillow 预览脚本、预览哈希校验及证据导入。
Harness 不直接调用视觉模型；Codex 生成标注准确率和真实多轮收敛仍需真实任务验收。
综合分作为进展指标；通过由图像维度、明确验收项分别达标及适用的关键区域检查决定。无标注明确为仅图像评测。

导入标注默认 diagnostic，不阻断验收，不提升主分；报告单独展示 annotation_diagnostics 和覆盖范围。
